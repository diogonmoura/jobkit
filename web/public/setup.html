Step 1 of 5

Connect Supabase

jobkit stores everything in your own Supabase project (the free tier is enough). The Worker reads three values from its configuration:

Where to find them
  1. Create a project at supabase.com/dashboard.
  2. Open Project Settings → Data API and copy the Project URL (https://<ref>.supabase.co).
  3. Open Project Settings → API Keys. Copy the publishable key (sb_publishable_…, or the legacy anon key). It is safe in the browser: Row Level Security protects your rows.
  4. On the same page copy the secret key (sb_secret_…, or the legacy service_role key). It bypasses Row Level Security, so it is stored only as a Worker secret and is never sent to the browser.

    Save the configuration

    Local development: put this in web/.dev.vars, then restart npm run dev.

    
        
    Cloudflare: set the public values in wrangler.jsonc vars and the secrets with Wrangler, then npm run deploy.
    
        
    
        
    SETTINGS_ENC_KEY was generated in your browser just now. It encrypts the AI key you save in step 3; keep it safe and do not change it later.
